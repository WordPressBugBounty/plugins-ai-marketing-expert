== Installation ==

**From the WordPress Plugin Directory:**

1. Go to **Plugins → Add New** in your WordPress admin
2. Search for **AI Marketing Expert**
3. Click **Install Now** and then **Activate**
4. Click **AI Marketing** in the left admin menu to get started

**Manual Installation:**

1. Download the plugin zip file
2. Go to **Plugins → Add New → Upload Plugin**
3. Upload the zip and click **Install Now**
4. Activate and go to **AI Marketing** in your admin menu

**Setup:**

1. Go to **AI Marketing → Settings → AI Providers** and add at least one AI connection (Google AI Studio is free to start)
2. Enable the modules you want from the Modules screen
3. Configure each module from its submenu page

== Frequently Asked Questions ==

= Does this plugin require an API key? =

AI-powered features (content generation, AI subject lines, chatbot, SEO analysis, social captions) require an AI provider API key. You can use Google AI Studio (Gemini) which offers a free tier, or OpenAI, Anthropic Claude, or OpenRouter. Non-AI features like SMTP email sending and subscriber management work without any API key.

= Which AI provider should I start with? =

Google AI Studio (Gemini) is the easiest to start with — it offers a free API tier with no credit card required. Sign up at ai.google.dev, create an API key, and paste it into AI Marketing → Settings → AI Providers.

= Is the email marketing feature really free with unlimited subscribers? =

Yes. The free tier includes unlimited subscribers and 30 campaigns per month. There is no subscriber cap on the free plan.

= Does the chatbot work with WooCommerce? =

Yes. The Pro plan allows you to index your WooCommerce product catalog into the chatbot knowledge base so it can answer product questions, check availability, and assist shoppers automatically.

= Can I use multiple AI providers at the same time? =

Yes. You can add multiple AI provider connections and assign different providers to different modules — for example, GPT-4o for content generation and Claude for your chatbot.

= Will this plugin slow down my website? =

No. All AI calls and email sending happen in the WordPress admin or via background WP-Cron jobs. The only front-end asset is the optional chatbot widget, which loads asynchronously.

= Does the social media scheduler support LinkedIn? =

Currently the plugin supports Facebook Pages, Instagram Business, and X/Twitter. LinkedIn support is planned for a future release.

= Is my data secure? =

Yes. All API keys and SMTP credentials are encrypted at rest using AES-256-GCM authenticated encryption. No subscriber data or conversation data is ever sent to third parties. Email tracking uses HMAC-signed URLs to prevent open redirect abuse.

= Can I import existing email subscribers? =

Yes. You can import subscribers from a CSV file, sync from WordPress registered users, or import WooCommerce customers.

= Where can I get support? =

Visit [wpthemespace.com/ai-marketing-expert](https://wpthemespace.com/ai-marketing-expert/) for documentation and support.

== Privacy Policy ==

AI Marketing Expert connects to third-party external services to deliver its AI-powered features. By using those features you agree to the respective terms and privacy policies listed below.

**AI Providers (used for content generation, chatbot responses, SEO analysis, social captions, and email copy)**

When you use any AI-powered feature, the text you submit (article topic, keyword, chat message, email copy, etc.) is transmitted to the AI provider you configured in Settings → AI Providers. No data is transmitted unless you have added and selected a provider.

* OpenAI — https://openai.com/policies/privacy-policy
* Anthropic (Claude) — https://www.anthropic.com/privacy
* Google AI Studio (Gemini) — https://policies.google.com/privacy
* OpenRouter — https://openrouter.ai/privacy

**Social Media Platforms (used for the Social Media Scheduler module)**

When you connect a social account and publish or schedule a post, the post content and your stored OAuth access token are transmitted to the respective platform API.

* Meta (Facebook & Instagram) — https://www.facebook.com/privacy/policy/
* X / Twitter — https://twitter.com/en/privacy

**What data is sent?**

* AI features: the text prompt or content you submit. No personal user data, subscriber emails, or visitor information is ever sent to AI providers.
* Social posting: the post text, images, and your OAuth credentials for the connected account.
* Email sending: email content is sent via the SMTP provider you configure. The plugin does not use or share any external email relay beyond the SMTP server you supply.

**What data is stored locally?**

* Subscriber records, email addresses, campaign history, conversation transcripts, and SEO reports are stored only in your WordPress database on your own server.
* API keys and SMTP passwords are encrypted at rest (AES-256-GCM) in your WordPress database. They are never transmitted anywhere other than the respective provider API.

**Data Retention**

All data (subscribers, conversations, campaign history, audit reports) is stored on your server and is fully under your control. Deactivating or deleting the plugin will not automatically delete database tables — you can remove them from Settings before deletion.
